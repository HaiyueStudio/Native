# @haiyue/native 0.1.2 — 待发布

本版本补充可配置广告奖励数量和通用分包/升级权益。保持现有平台适配及 SDK 依赖版本；不修改示例应用版本，也不迁移私有游戏。

## 广告奖励数量

- `RewardController` 和 `createRewards` 接受可选 `rewardAmount`，默认 1；配置 3 即每次有效广告奖励增加 3 个额度。
- `snapshot().rewardAmount` 供界面显示准确的奖励数量。参数只接受正安全整数，额度溢出在播放前拒绝。
- 一次成功广告仍只消耗一次广告次数；保留重复回调去重、取消不发奖、持久化及跨日余额语义。现有钱包无需迁移，不重新计算历史余额。

## 分包与升级购买

- `@haiyue/native/purchases` 新增 `PurchaseCatalog`，组合基础包、高级包、完整版以及要求先拥有基础权益的升级商品。
- 完整版可授予多个包权益；分别购买全部包也能组合成完整版权益。已覆盖的商品不能重复购买。
- 购买前刷新并核验前置权益；恢复顺序不影响结果，基础包退款后撤销依赖它的升级权益。购买过程在同一目录内串行执行。
- 每个商品价格由 App Store Connect / Play Console 单独配置。支持直购完整版比单独购买便宜，但不提供商店自动补差价或本地金额相减扣款。没有 iOS / Android 互通购买。
- `dispose()` 只清理目录订阅，底层商品控制器仍由宿主负责释放。

接入示例见 [商业化说明](../bridge/monetization/README.md)。新增 API 继续按实验性能力交付；源码/包验证不能代替消费应用上的 StoreKit Sandbox、Play Billing、AdMob/UMP 真机验收。
