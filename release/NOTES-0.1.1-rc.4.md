# 0.1.1-rc.4：单仓库构建候选

- 将五款游戏的实际冻结源码、自有图片和音效纳入 games/，保留原许可与逐文件来源哈希。
- Sky Strike 显式使用自身 vendor 扩展包的 indexed-sprite 类型入口，避免类型检查借用旧 Games 的 node_modules。
- 原生入口、素材脚本、候选冻结及导入闭包校验不再访问相邻 Games 仓库。
- Sky Strike 与 AK47 的转换脚本纳入 Native；所有大块运行纹理均在构建时重新生成。
- 无再分发授权的三个模型通过 local-assets/ 或 HAIYUE_MODEL_ASSETS 提供。原生验证单独记录并检查它们的哈希。
- 增加 release:export，可将冻结的公开输入导出到全新目录；不会携带依赖安装目录、构建产物、签名或模型。
- 为六个 Gemfile.lock 补齐 Bundler 生成的校验和，修复全新目录冻结安装失败；依赖版本及平台未变。冻结入口会拒绝空校验和。
- 固定 NativeScript 的生成 hook，避免首次构建新增发布输入；为 Podfile 增加去除绝对路径注释的参考文本，同时继续验证实际校验和、Ruby 正文及依赖锁，支持任意检出目录。
- iOS 构建支持 generic/platform=iOS，无须依赖手机当前连接状态；签名仍通过开发者自己的 Team 配置。

游戏实现、依赖版本和应用版本沿用 0.1.0；源码候选单独递增，不覆盖已发布标签。此次全新目录构建结果保存到 evidence/0.1.1-rc.4/。该结果不代表重新完成所有真机交互验收，也不代表应用商店发布。
