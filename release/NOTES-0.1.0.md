# Native 0.1.0 源码版

首个 Native 源码版本提供共享移动端桥接和六个公开示例：PBR Orbit、蜘蛛纸牌、Sky Strike、魔方、AK47 Range、Neon Circuit。六个示例支持 iOS；Neon Circuit 另有 Android 实现。

## 包含内容

- NativeScript Canvas / WebGPU 渲染宿主、触摸输入、生命周期、音频、存档，以及 iOS / Android 震动与陀螺仪适配。
- Neon Circuit 临时空表面纹理恢复：在场景更新前取帧、缓存同帧纹理，短时失败退避重配表面，保留游戏实例；重试耗尽和其他 GPU 错误仍明确失败。
- 精确依赖与工具链记录、输入 SHA-256 清单、统一源码与原生构建验证入口。
- 代码采用 MIT；第三方软件与素材保持各自许可。独立开发者使用自己的平台账号和签名配置，见 [签名指南](SIGNING.md)。

## 重建与验收

环境、依赖安装和构建命令见 [发布说明](README.md)。各应用版本为 0.1.0，测试使用签名 Debug 真机构建，不是商店分发包。验收范围和证据见 [验收记录](ACCEPTANCE.md)。

Native 源码仍依赖相邻 Games 工作目录；候选清单记录实际 Games 输入哈希，不能只凭基线提交推定所有未提交输入相同。本版本不承诺下载 Native 单仓即可独立构建全部游戏。

## 素材范围与限制

本次不附带 GLB 模型、生成游戏素材、APK / IPA / AAB 或签名凭据。用户提供模型来自技术交流群，用户告知仅限非商用，原作者及完整许可无法核实；这些模型不属于 Native 的 MIT 授权。开发者应自行取得相应授权或替换模型，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

真机验收覆盖记录中的设备和场景，不代表全部 iOS / Android 型号或最低系统版本均已通过，也不代替长期温升和全关卡平衡测试。魔方当前按操作历史还原，公式求解未包含在 0.1.0 中。
