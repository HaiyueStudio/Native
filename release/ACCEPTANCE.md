# 0.1 源码发布真机验收

2026-09-24，六个公开示例均在 iPhone 15 Plus / iOS 18.7.3 上完成下表范围的验收。使用付费开发者 Team 签名的 Debug App。Neon Circuit 的 Android 验收设备为 X4000 / Android 14。

| 示例 | 结果 | 本次实际覆盖 |
| --- | --- | --- |
| ios-pbr-orbit | 通过 | 冷启动、PBR 画面、真实拖动 Orbit、相机角度变化、前后台恢复 |
| spider-solitaire | 通过 | 三档难度、发牌 50→40、撤销 40→50、非法拖放拒绝、合法 J→Q 拖放、冷启动恢复牌局和步数 |
| sky-strike | 通过 | 首页进入战斗、真实移动与射击、敌人/伤害、暂停、13 种 Boss/精英部件诊断、音频后端与前后台恢复 |
| rubiks-cube | 通过 | 二/三/四阶及镜面选择、分别打乱 16/25/40/25 步后复原、面拖动、内层旋转与撤销、横竖屏、前后台恢复 |
| ak47-range | 通过 | 47 项原生自动断言：双摇杆、装填、敌人模型/死亡/移除、遮挡/雷达、安全区及震动请求；正常启动和真实前后台恢复 |
| neon-circuit | 通过 | iOS 106 项原生自动断言：七赛道、控制、音频、GUI、特殊赛道；正常启动与真实前后台恢复。Android 29 项断言及 5 轮真实前后台恢复 |

六个应用恢复后均有后续帧增长，所收集日志没有致命渲染错误。XCTest 共执行 9 个 UI 流程，无失败；结果同时通过游戏状态日志与关键截图核对，未仅依赖 XCTest 的退出码。

- iOS 构建、实际安装包逐文件哈希、原生断言、宿主日志、UI 流程源码和截图保存在 [rc.3 验收目录](evidence/0.1.0-rc.3/README.md)。
- Android APK 哈希、空表面纹理故障注入、29 项断言与 5 轮恢复保存在 [rc.2 验收目录](evidence/0.1.0-rc.2/README.md)。[输入比较](evidence/0.1.0-rc.3/rc2-runtime-equivalence.json) 确认 rc.2 → rc.3 的桥接、示例及 Games 输入完全相同，变更仅涉及发布文档与根版本配置。这里复用相同运行代码的 Android 证据，不声称重新执行了 Android 测试。
- 正式 0.1.0 与 rc.3 的运行输入比较及最终源码检查保存到 evidence/0.1.0/。若桥接、示例、vendor 或 Games 输入不同，不能复用上述真机结果。

## 范围与复验

该结论用于 Native 0.1 源码发布。未覆盖所有设备/最低系统组合、全关卡通关、长时间温升压力或商店分发；PBR 示例本来禁用缩放，没有将多指缩放列为通过。震动记录证明原生请求及调用路径，强度的主观体验仍需人工评估。模型许可与签名说明分别见 [第三方声明](../THIRD_PARTY_NOTICES.md) 和 [签名指南](SIGNING.md)。

复验时先通过统一构建入口，再安装当前产物；记录候选和安装包哈希、设备系统与时间。显式原生验证模式为 `NEON_VERIFY=1`、`RANGE_VERIFY=1`；其他流程参照证据目录中的 XCTest 源码及日志。图像和报告需要检查本次启动时间，不能使用设备上遗留文件冒充新结果。测试结束用无诊断参数的普通启动恢复应用。

后续改动运行代码或依赖时，应创建新候选并重验受影响应用；prepare 成功、截图生成或源码测试通过都不能单独代替真机验收。
