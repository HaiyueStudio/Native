`generation-comparison.json` 是桌面单次固定种子对照，before 为本次修改前的生成策略，after 为当前策略；耗时受预热影响，不作为严格性能基准。数比＋奇偶已知数 25→20，增加杀手＋连续线后 25→10；四项进阶标准题 25→6。算法优先减少已知数，再按分组试删符号；删除也需验证唯一解。复杂挑战的额外证明可能增加耗时，因此设置了确定性搜索节点预算，不能证明的线索保留。最终真机耗时见 `smoke-host.jsonl` 的 `generation-timing`。

保留每个启用规则的至少一个标记（多对角线至少两条），不声称全局线索最少。XV/白点的“全部标出”以及杀手笼覆盖保持完整。已有玩家棋局不重新生成，精简策略在新开棋局时生效。
