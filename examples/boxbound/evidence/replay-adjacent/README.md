# 重玩按钮、相邻盒子转场与墙顶圆角

右上角增加当前小关卡重玩按钮，可撤销，独立关卡外禁用。五个图标可见尺寸缩小 20%，不透明度 75%；保留原有触控范围。跳跃、下钻采用内置 image_gen 生成的圆形按钮，继续响应 pointerdown。素材和完整提示词见 `../../src/assets/ui/buttons-generation.json`。

Reference 5 从红盒出口进入相邻蓝盒时，一次移动实际包含“离开红盒、进入蓝盒”两个物理边界。之前只记录第一个边界，保留场景和原角色使用了错误的缩放/平移。现在记录完整边界序列，组合空间变换；撤销反转顺序及方向。不会改变红盒实际位置，也不会额外生成角色替身。浏览器验证首帧投影连续、中途缩放、原角色实体复用及撤销。

墙顶此前统一沿同一对角线切分网格，右上和左下角出现指向外角的凸脊。改为选取高度较低的对角线，四角保持旋转和镜像对称；不增加顶点或三角形，墙顶仍为每格 32 个三角形，L/T 连接保持连续。测试先复现原网格的旋转不对称，再验证修复。

验证范围仅 Boxbound，未修改引擎。`validation.json` 记录测试结果；`iphone.png` 为 iPhone 15 Plus 真机渲染，`browser-wall-corners.png` 为独立墙、L/T 墙专项画面。iOS 指针检查通过引擎事件入口注入，不等同于 UIKit 真手势自动化。真机测试使用隔离存档，测试后恢复普通启动。
