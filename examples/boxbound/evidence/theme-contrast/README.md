# 地图盒子配色辨识度

Reference 6 的原配色为蓝色地图 / 淡紫色子地图，两只地图盒子的外壳还统一使用普通箱子的蓝色。现在 Reference 6 为玫瑰红地图及同色递归盒子，另一个内部地图为青绿色。

地图主题在加载时根据有限引用图分配，以色相差选择父子地图配色，并兼顾同一场景里并排的地图盒子。循环引用完成分配后再检查邻居，修复接近的色系。自身引用、克隆和镜像仍使用被引用地图的配色；移动、重置、进入与退出不会重新分配主题。显式 JSON theme 仍保留作者优先级。

地图盒子的透明外壳、末级 LOD 实体及顶部标识改用其内部地图主题；普通实心箱子和目标标记的颜色规则不变。缩略与完整地图继续共享主题材质，没有新增几何体或每帧配色计算。

扫描全部 406 个地图、456 条非自身嵌套引用，色相差小于 80° 的引用从 151 条降为 0 条。`before.json` / `after.json` 中 `close` 列的是小于 90° 的组合；保留的红/绿色组合约为 85°，不属于接近色系。测试同时检查全量引用、确定性、主题覆盖、递归一致性和 LOD 进入后的颜色一致性。没有修改引擎或执行全库测试。
