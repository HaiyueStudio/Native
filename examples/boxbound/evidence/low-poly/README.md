# 平地砖与圆弧墙顶（2026-09-22）

地砖改为每格两个三角形的平面，移除厚度、圆角和细缝。目标框同时降低。不可站立墙移除九宫格凸点，使用每格 32 个三角形的圆弧顶；墙侧只生成暴露边，相邻格子保持连续的高度和法线。普通可站立平台保留平顶，碰撞规则不变。父级、当前地图和盒内 LOD 使用一致模型和材质。相同墙形跨房间复用几何体，支持引擎合批。

## 真机统计

X4000 / Adreno 710，渲染 1600×720。以下均为关闭阴影的样本；同样八次跳跃工作负载，对照上一版 `../shadows/validation.json`。两次启动之间没有控制温度或系统调度，帧耗时仅作参考，不能用面数降幅代替帧率提升。

|---|---:|---:|---:|---:|
| 大世界 | 799,320 → 226,148 | 71.7% | 243 → 245.7 | 18.97 → 21.08 ms |
| Intro 1 | 1,077,356 → 171,784 | 84.1% | 159 → 120.4 | 19.95 → 18.80 ms |
| Reference 1 | 506,772 → 95,730 | 81.1% | 292 → 257 | 21.70 → 17.54 ms |

总数按已加载 3D 模型实例计数，包含完整父场景及子盒子预览，不含 HUD 和额外阴影提交。小关卡 draw call 和帧耗时有所降低；大世界 draw call 基本持平，帧耗时本轮反而较高，没有观察到帧率提升。后续应继续检查绘制提交与材质批次，不能认为仅减少面数即可解决所有卡顿。

## 验证

- Boxbound 规则、性能、模型定向单测首轮 230 项通过；最终新增几何复用检查后，5 项模型测试通过，两轮合计 231 个不同检查。
- 移动端单测 13 项、真机 26 项通过。
- 最终浏览器检查 186 项通过：可读性与移动、递归连续性、盒内外配色、上台阶、下台阶。
- Games 与 Native 类型检查、Boxbound 定向网页构建、安卓构建通过。
- 未改动引擎，没有执行全库测试。

`profile.jsonl` 是最终完整日志，`validation.json` 包含统计与文件指纹。`first-pass.jsonl` 保留墙体几何尚未跨房间复用时的探索数据，不参与最终汇总。截图为 `android-final.png` 和 `browser-*.png`。
