# 关闭阴影性能对照（2026-09-22）

默认禁用两盏方向光的阴影，保留光源颜色、强度、环境光、材质和相机。没有改动引擎。

X4000 / Adreno 710，渲染分辨率 1600×720。一次启动内，每个场景按开、关、关、开测量，每段先预热，再重复 8 次原地跳跃；仅统计活动帧，排除跳跃间空闲。启动第 120 帧截图在测量之前完成。数值为两段同模式按样本数加权的平均值。

| 场景 | 帧间隔：开 → 关 | 帧耗时下降 | Draw call：开 → 关 | 已加载三角形 | 视锥内保守估算 |
|---|---:|---:|---:|---:|---:|
| World | 31.59 → 18.97 ms | 40.0% | 433 → 243 | 799,320 | 799,320 |
| Intro 1 | 48.95 → 19.95 ms | 59.2% | 580 → 159 | 1,077,356 | 233,380 |
| Reference 1 | 51.33 → 21.70 ms | 57.7% | 498 → 292 | 506,772 | 302,260 |

三角形按实际实例重复计数，包含完整父级、当前地图及子盒子 LOD，排除 GUI 和阴影额外重复提交。`inFrustum` 为相机视锥与模型包围球相交的保守估算，不表示最终像素可见或准确提交数；引擎空间索引还有 AABB 粗筛。Intro 1 包围球统计 199 个模型，关闭阴影时引擎粗筛后为 183 个。

Reference 1 的墙顶圆点占 254,016 个三角形（约占总数 50%）；后续减少凸点细分或采用更低细节的盒内预览有优化空间，本次保留造型不变。

验证：Games / Native 类型检查、Boxbound 网页定向构建及安卓构建通过；226 项 Boxbound 单测、13 项移动端单测、47 项浏览器递归检查、26 项真机检查通过。引擎没有新增改动，因此未跑全库测试。

原始数据：`ab.jsonl`，汇总及源文件指纹：`validation.json`。`warmup-draft.jsonl` 为未排除启动截图的初轮探索数据，不参与最终汇总。浏览器截图为 `browser-reference-continuity.png`。

复现：构建/安装本目录安卓调试包后，`node scripts/device.mjs stop`、`node scripts/device.mjs launch smoke`、等待回归结束，再用 `node scripts/device.mjs journal evidence/shadows/ab.jsonl` 读取诊断。使用独立 smoke 存档，正常启动不执行基准测试。

限制：这是带诊断的同设备短时 A/B 对照，未取得独立 GPU 时间；帧率换算不能视为全游戏持续帧率。关闭阴影后仍未稳定达到 60 FPS。
