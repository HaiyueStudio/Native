# Sky Strike 三处性能优化与真机复测（2026-09-15）

优化版已构建、签名、安装并启动。测试结束后已恢复普通游戏，性能采集关闭；normal-host.jsonl 确认正常 present 且无 performance 事件。

## 改动与正确性

- 普通弹幕按最多 32 颗的窗口检查完整光晕/弹体包围盒。仅对互不重叠的子弹先合并光晕、再合并弹体；重叠、泡泡、反弹弹和棱镜碎片保持原有顺序。透明渲染器本身不按材质重排。
- IndexedSpriteRenderer 复用准备记录、实例 ArrayBuffer/TypedArray 和视口数据，按容量增长、仅上传实际使用字节；已排序输入免排序。默认 tint/colorMatrix 使用常量。错误后清除命令引用，销毁时释放缓存，无新增公共 API。
- 战场复用精灵命令对象；关卡预览使用独立命令与渲染器，避免污染待提交帧。
- 敌方子弹碰撞改为倒序索引遍历，移除整数组复制、reverse 和每颗子弹的 indexOf。损失生命后的前缀清除精确修正游标；不改变伤害、目标优先级或复活无敌期间的陨石遮挡。

Chrome/Metal + 4× MSAA 实际像素回归：504 条命令，draw calls 339 → 25，RGBA 字节差异为 0（含重叠、旋转及特殊子弹）。100 帧命令对象复用与实例上传缓冲身份检查通过。24 次首次/缓存关卡预览切换像素不变。复活前缀删除、陨石拦截及数值平衡回归通过。

## 真机结果

同一 iPhone 15 Plus，860×1864、4× MSAA、轻量 SKY_PERF=1。相同脚本、同一组场景；黑洞日志首次截止尚未暂停，随后补取同一次运行的完整日志（partial 文件保留）。不改分辨率、素材、弹幕数量、伤害或特效。

量子场景追加一次复测：帧处理墙钟均值 17.02 ms，回调 52.2 Hz，间隔最差窗口 P95 30.25 ms。两次均保留，未挑选最好结果替换首次采样。绘制调用明显下降，但部分场景墙钟/间隔变差；**本轮不能确认整体帧率稳定提升，也不能据此认定 GPU 或 CPU 执行时间下降**。当前已确认的收益是减少绘制状态切换、临时数据分配及碰撞重复查找。

所有采样 thermalState=0。主精灵图集始终 47,914,992 字节；黑洞临时目标峰值 32,060,800 字节，结束时为 0。复用增加有上限的 CPU 缓存，不增加纹理或 GPU 实例缓冲容量。未测总进程 RSS、真实 GPU 执行时间、GC 暂停、耗电或长时间内存增长。
