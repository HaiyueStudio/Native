# 日历拼图提示缓存与求解剪枝（2026-09-20）

## 实现

- 缓存最多 16 个完整解。后续已摆方块与完整解占用格子一致时直接复用，不启动 Worker；对称旋转、翻转按实际格子比较。
- 玩家改变已摆方块、缓存不兼容时重新计算；纠错解仅对原来的同一局面复用。取消的请求仍可将已完成的完整解写入缓存，但不会展示过期提示。
- 免费次数用完时直接展示广告/解锁选项；不会先求解再发现没有次数。已消费的同一提示仍可重复查看。
- 搜索保留 Algorithm X / DLX 最小候选列选择，增加连通区域面积与剩余方块数量分配剪枝，以及黑白格数量差的必要条件检查。区域检查只在拼图形状满足对应数学前提时启用。
- 使用最多 20,000 个无解状态跳过重复搜索，状态包含占用格子及剩余方块身份。只缓存完整搜索得出的无解，不缓存超时结果。
- 用数字索引访问棋盘，限制候选摆法的有效边界，仅为已摆方块建立位置索引，减少字符串、排序和临时对象开销。

## 正确性

- 提示/求解/动画专项测试 15/15；覆盖 84 个日期组合、对称摆法、错误摆放、取消/超时恢复、缓存上限和日期隔离。
- 枚举一个完整解的全部 1,024 个子集，每个都必须在保留已摆方块的前提下求解成功，不能以纠错回退掩盖错误剪枝。
- 两个固定回归局面的搜索节点分别从 1,530 降为 1,150、1,946 降为 1,370。
- Native 测试 53/53；Games 与 Native TypeScript 检查通过。
