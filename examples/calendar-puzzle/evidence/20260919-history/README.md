# 日历拼图 · 通关动效与万年历验证

## 功能

- 通关时弹出大拇指，带弹性缩放和 72 个彩色粒子；单张缓存图标、固定粒子池，约 4 秒后停止动画更新。提供继续/查看记录操作。
- 右侧日期入口切换为万年历，单箭头切月份、双箭头切年份；选日后自动计算星期并返回棋盘。支持公历 1–9999 年、世纪闰年和跨年边界。
- 已通关日期浅绿色，当前选中日期绿色边框；日期记录包含完整年月日并去重，切换日期或打乱不删除历史。
- 中文、英语、日本語同步更新日历、胜利面板和设置；旧存档可读取。
