# 极速新星：手机与引擎性能优化

2026-09-15，在同一台 iPhone 15 Plus（A16）上验证。已安装更新。

## 结果

保持 1864 × 860 渲染分辨率、4× MSAA、反转 Z、原有场景和赛车材质。使用莫比乌斯星环、困难人机竞速，玩家停在起点，镜头固定、人机持续行驶；两版都显式启用相同性能采样。排除启动阶段，比较以第 240–4800 帧结束的采样窗口，共 4680 个帧间隔。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 平均帧间隔 | 21.80 ms | 19.85 ms |
| 对应平均帧率 | 45.87 FPS | 50.37 FPS |
| 每帧管线切换（采样均值） | 507 | 49.33 |
| 每帧缓冲区上传次数（采样均值） | 45.33 | 36.49 |
| 每帧上传字节（采样均值） | 30,800 | 28,487 |
| 每帧绘制次数（采样均值） | 514 | 513 |
| 第 4800 帧存活 GPU 缓冲区 | 39,518 | 929 |
| 第 7200 帧存活 GPU 缓冲区 | 44,360 | 923 |

帧率约提高 9.8%，管线切换减少约 90.3%。优化后持续运行到第 7920 帧，GPU 缓冲区仍为 923；比赛结束后少量 HUD 缓冲区正常释放，没有继续增长。

**降温尚未得到证实。** 两版长时间运行后都达到 iOS thermalState 2（serious）；优化版第 4800 帧已为 2，基线该帧为 1。此测试未控制环境温度、充电功率与机身初始温度，不能把帧率提升等同于功耗或温度下降。此次解决了资源泄漏和无效命令，持续高画质渲染仍有较大 GPU 负担。

帧间隔包含调度与 GPU 背压；CPU 回调计时包含 present 等待，不代表纯 CPU 忙碌时间。未取得 GPU 执行时间、功耗或机身温度测量，资源估算也不等于进程 RSS。固定起点测试不是玩家连续驾驶多局的完整替代。

## 改动

- Engine GUI 图片缓冲区改由稳定的 batch/source 持有，修复每次界面重建创建新缓冲区、旧缓冲区无法释放的问题；覆盖空批次、扩容、移除和重建后的释放。
- 重用图片顶点数组，未变化的图片不重复上传；重复设置相同样式、UV 不再让 GUI 重建。
- 引擎渲染通道复用相同管线、绑定组、顶点与索引缓冲区绑定。覆盖主场景直接通过 command encoder 开启的独立通道；动态偏移按值快照，Render Bundle 后清空状态，新通道不复用旧状态。
- 健康车身火焰只初始化一次；暂停时停止重画不变的火焰、尾焰、加速带纹理。残血动画仍持续更新，修复车身后清除火焰。
- 小地图改用数值比较，避免每帧构造浮点字符串；隐藏踏板不更新，静止方向盘不触发 GUI 布局。
- 普通手机游玩将完整日志写入间隔由 120 帧延长为 600 帧；性能采样只在 `NEON_PERF=1` 开启，内存样本数量有上限。

## 验证

- Engine 627 项测试通过，包含新 GPU 缓冲区生命周期、上传预算、绑定状态复用测试；引擎与全仓类型检查通过。
- 447 个引擎模块边界检查、职责边界、renderer prepare 检查通过。
- 极速新星 78 项规则测试、类型检查、目标构建通过。
- Native 10 项测试、类型检查和设备构建通过；53 个资源逐字节校验通过。
- 最终真实 WebGPU 场景：空间人机赛 22 项、高速手机布局 74 项、残血火焰 71 项，共 167 项检查通过；截图已人工查看。
- 动态纹理预算：120 帧健康行驶的三种纹理提交从原来的 360 次降到 241 次；冻结时间后 120 帧提交与上传均为 0；销毁后缓冲区和纹理残留为 0。
- 完整 Games 测试仍有与本次无关的 HYMUGEN 字节序列化、viewer UI slot 断言失败和 4 项 Petra 超时。Engine API 总检仍受已有 UI capability/export 不匹配影响。完整 Engine build 的共享示例包曾触发默认 60 秒超时，随后使用可配置的 180 秒构建超时重建相关 GUI 示例。
